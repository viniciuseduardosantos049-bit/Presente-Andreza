## Como executar localmente
Opção 1 — abrir direto:
1. Clone o repositório:
   git clone https://github.com/viniciuseduardosantos049-bit/Presente-Andreza.git
2. Abra `index.html` no navegador.

Opção 2 — usar servidor local (recomendado para testes de JS que usam fetch/history):
1. Instale uma extensão como "Live Server" no VS Code ou use um servidor simples:
   - Python 3: `python -m http.server 8000`
2. Acesse `http://localhost:8000`

1. Vá nas configurações do repositório > Pages
2. Escolha a branch (ex.: `main`) e a pasta (`/root` ou `/docs`)
3. Salve e aguarde o link gerado

## Personalização rápida
- Troque textos e imagens em `index.html`
- Ajuste cores no arquivo CSS principal
- Edite mensagens dinâmicas no `main.js`

## Testes
- Verifique em diferentes tamanhos de tela

## Perguntas frequentes
- Posso adicionar música ao site? Sim — adicione uma tag `<audio>` com controle ou autoplay (atenção a UX).
- Como deixar o site privado? Hospedagem estática pública não é privada; use hospedagem que suporte autenticação se necessário.
