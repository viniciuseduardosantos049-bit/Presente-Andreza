# 🎁 Presente-Andreza

Um site especial criado como presente para a minha esposa Andreza! 💕

## 📋 Sobre o Projeto

Este projeto é uma aplicação web interativa desenvolvida com HTML, CSS e JavaScript. O objetivo principal é criar uma experiência única e personalizada, com múltiplas páginas e funcionalidades especiais.

### ✨ Funcionalidades Principais

- **Página Principal Responsiva**: Design moderno e adaptável para todos os dispositivos
- **Múltiplas Versões**: Diferentes versões do site para explorar diferentes estilos e abordagens
- **Comparador de PDFs**: Ferramenta interativa para comparação de documentos
- **Exemplos de PDFs**: Galeria com exemplos de funcionalidades
- **Servidor Local**: Suporte para execução local com Node.js

## 🚀 Como Usar

### Instalação
1. Clone o repositório:
```bash
git clone https://github.com/viniciuseduardosantos049-bit/Presente-Andreza.git
cd Presente-Andreza
```

2. Instale as dependências:
```bash
npm install
```

### Executar Localmente
Para rodar o servidor de desenvolvimento:
```bash
node server/frontend-server.js
```

Ou a versão 2:
```bash
node server/server-v2.js
```

Abra seu navegador em `http://localhost:3000` (ou a porta configurada)

## 📂 Guia de Organização

A estrutura do projeto foi reorganizada para melhor manutenibilidade e escalabilidade:

- **src/** - Todo o código-fonte frontend
  - **pages/** - Arquivos HTML das páginas
  - **styles/** - Folhas de estilo CSS
  - **scripts/** - Lógica JavaScript
  - **assets/** - Imagens e recursos estáticos

- **server/** - Arquivos de servidor Node.js
- **config/** - Arquivos de configuração e variáveis de ambiente
- **docs/** - Documentação e arquivos adicionais
